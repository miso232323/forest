## 1. 프로젝트 개요

### 1.1 프로젝트명
**숲길 따라 — 아침고요수목원 겨울 여행 가이드**

### 1.2 프로젝트 목적
겨울철 아침고요수목원을 방문하려는 여행객에게 계절의 매력과 실용적인 여행 정보를 에디토리얼 형식으로 제공하고, 방문 인증 이벤트를 통해 실제 방문 및 제휴 카페 이용을 유도하는 반응형 홍보 랜딩페이지를 구축한다.

### 1.3 핵심 가치
- 겨울 정원과 숲의 아름다움을 감성적인 이미지와 스토리로 전달한다.
- 겨울 체험 콘텐츠와 방문 준비 정보를 쉽고 직관적으로 제공한다.
- 방문 인증 이벤트를 통해 참여를 유도한다.
- 인증된 참여자에게 카페 음료 50% 할인 쿠폰을 발급하는 흐름을 제공한다. 단, 할인 혜택은 수목원 및 카페 운영 주체의 공식 승인을 전제로 한다.

### 1.4 성공 지표(KPI)
- 메인 CTA 클릭률
- 겨울 체험 및 방문 Tip 섹션 도달률
- 쿠폰 이벤트 진입률
- 인증 신청 완료율
- 인증 승인율 및 쿠폰 발급 수
- 쿠폰 사용률
- 모바일 페이지 이탈률 및 주요 화면 성능

초기에는 측정 기준값을 수집하고, 실제 운영 데이터가 확보된 뒤 목표치를 설정한다.

## 2. 타깃 사용자

### 2.1 핵심 타깃
자연과 식물을 좋아하는 30대 성인 남녀.

### 2.2 방문 동기 및 관심사
- 연인 또는 친구와 함께하는 겨울 나들이
- 자연 풍경과 정원 산책
- 감성적인 사진 촬영
- 식물과 계절 생태에 대한 관심
- 일상에서 벗어난 조용한 휴식
- 겨울 야간 정원 및 계절 행사 관람

### 2.3 제외 대상 및 콘텐츠 정책
- 반려동물 동반 방문객을 핵심 타깃으로 설정하지 않는다.
- 반려동물 동반 가능 여부를 확인하지 않은 상태에서 동반 입장을 암시하지 않는다.
- 수목원의 실제 입장 정책과 다른 안내를 제공하지 않는다.

## 3. 브랜드 및 디자인 방향

### 3.1 콘셉트
**Natural Editorial — Winter Edition**

여행 전문 매거진처럼 자연 풍경, 감성적인 문장, 충분한 여백을 활용한다. 화려한 장식보다는 겨울 숲의 이미지와 정보의 위계를 중심으로 구성한다.

### 3.2 핵심 카피
- 메인: **겨울이 머무는 숲으로**
- 서브: **하얀 겨울 숲에서 만나는 초록의 생명력. 오늘은 자연의 속도에 맞춰 걸어보세요.**
- 브랜드 메시지: **겨울, 자연을 가장 가까이 만나는 시간. 숲길 따라.**

### 3.3 컬러 시스템

| 토큰 | 색상 | 용도 |
|---|---|---|
| Snow White | `#FFFFFF` | 기본 배경 |
| Warm Ivory | `#F5F4EF` | 보조 배경 및 콘텐츠 영역 |
| Forest Green | `#234B38` | 주요 포인트, CTA, 제목 강조 |
| Sage Green | `#A8BBA8` | 보조 포인트, 아이콘 |

색상 대비는 WCAG AA 수준을 목표로 한다. 작은 글자에 연한 세이지 컬러를 단독 텍스트 색상으로 사용하지 않는다.

### 3.4 타이포그래피
- 제목: 한국어 명조 계열 또는 세리프 계열
- 본문 및 UI: 가독성 높은 한국어 산세리프
- 제목과 본문 사이의 크기·굵기 대비를 명확히 한다.
- 본문은 모바일에서도 읽기 편한 크기와 줄 간격을 유지한다.

### 3.5 이미지 아트 디렉션
- 실제 아침고요수목원의 겨울 풍경을 우선 사용한다.
- 눈 덮인 정원, 겨울 나무, 온실의 초록, 야간 정원 등을 콘텐츠 목적에 맞게 배치한다.
- 생성 이미지 또는 스톡 이미지를 실제 장소의 공식 사진처럼 오인하게 표현하지 않는다.
- 실제 장소 사진은 사용 권한 및 출처를 확인한다.
- 이미지마다 대체 텍스트를 제공한다.

## 5. 기능 및 콘텐츠 요구사항

### 5.1 Header / Navigation
**요구사항**
- 브랜드명 「숲길 따라」와 기본 메뉴를 표시한다.
- 데스크톱에서는 가로형 내비게이션을 사용한다.
- 모바일에서는 접근 가능한 메뉴 버튼과 펼침 메뉴를 제공한다.
- 스크롤 시 헤더의 가독성을 유지한다.
- 메뉴 클릭 시 해당 섹션으로 이동한다.

**완료 기준**
- 모든 메뉴가 올바른 섹션으로 이동한다.
- 키보드로 메뉴를 탐색할 수 있다.
- 모바일 화면에서 메뉴가 콘텐츠를 가리지 않고 정상 작동한다.

### 5.2 Hero — 첫 화면
**헤드라인**
> 겨울이 머무는 숲으로

**본문**
> 하얀 눈 아래 숨 쉬는 자연, 그리고 우리만의 겨울 산책. 계절이 빚어낸 정원에서 겨울만의 특별한 순간을 발견하세요.

**CTA**
- 「겨울 숲 여행 시작하기」 — Winter Garden 또는 Experience 섹션으로 이동
- 「방문 정보 보기」 — Visit 섹션으로 이동

**요구사항**
- 큰 겨울 풍경 이미지와 절제된 텍스트를 사용한다.
- 텍스트 대비를 확보하기 위해 필요하면 이미지 오버레이를 사용한다.
- 이미지 로딩 전에도 레이아웃이 흔들리지 않도록 비율을 지정한다.

### 5.3 About
- 아침고요수목원에 대한 간결한 소개를 제공한다.
- 실제 공식 소개 및 확인된 사실을 바탕으로 작성한다.
- 검증되지 않은 수상 경력, 규모, 연혁, 식물 수 등의 숫자를 임의로 기재하지 않는다.

### 5.4 Winter Garden
겨울철 관람 포인트를 사진과 짧은 설명으로 소개한다.

예시 콘텐츠:
- 겨울 정원 산책
- 겨울에도 푸른 상록수와 침엽수
- 온실 또는 실내 식물 관람(실제 운영 여부 확인 후 게시)
- 오색별빛정원전 등 겨울 시즌 행사(해당 연도 운영 일정 확인 후 게시)

각 콘텐츠에는 다음 필드를 사용한다.
- 제목
- 설명
- 이미지
- 운영 기간 또는 관람 가능 시간(확인된 경우에만)
- 공식 정보 링크(가능한 경우)

### 5.5 Experience — 겨울 체험 프로그램
- 실제 운영이 확인된 프로그램과 상시 관람 콘텐츠를 구분한다.
- 연도별 행사 일정이 미확정이면 날짜를 임의로 생성하지 않는다.
- 운영 여부, 예약 여부, 참가비, 연령 제한, 운영 시간은 공식 출처를 확인한 뒤 노출한다.
- 확인되지 않은 항목은 “공식 공지 확인 필요”로 표시하거나 게시하지 않는다.

### 5.6 Winter Tip — 인포그래픽
겨울 방문 준비 정보를 아이콘과 짧은 설명으로 전달한다.

| 항목 | 안내 문구 |
|---|---|
| 신발 | 눈과 얼음에 대비해 접지력이 좋은 미끄럼 방지 신발을 착용하세요. |
| 보온 | 내복, 니트, 방풍 외투를 겹쳐 입어 체온을 유지하세요. |
| 방한 소품 | 장갑, 목도리, 귀마개 등으로 노출 부위를 보호하세요. |
| 촬영 준비 | 추운 날씨에는 배터리가 빨리 소모될 수 있으니 보조배터리를 준비하세요. |

인포그래픽은 모바일에서 세로형 카드로 재배치한다. 아이콘만으로 의미를 전달하지 말고 텍스트 라벨을 함께 제공한다.

### 5.7 Eco Story — 겨울 생태 정보
**300자 이내 개요 초안**

> 겨울 숲은 멈춰 있는 공간이 아닙니다. 소나무와 상록수는 추운 계절에도 잎을 유지하며 광합성을 이어가고, 낙엽수는 휴면 상태로 에너지를 아낍니다. 눈과 서리는 식물과 숲의 풍경을 바꾸고, 겨울 숲은 계절마다 다른 생태의 모습을 보여줍니다. 방풍·보온 외투와 장갑, 목도리, 미끄럼 방지 신발을 준비해 안전하고 따뜻한 산책을 즐겨보세요.

생태 정보는 식물 종별 특성을 과도하게 일반화하지 않도록 검토한다. 필요하면 식물 이름과 설명을 공식 또는 신뢰할 수 있는 생태 자료로 확인한다.

### 5.8 Visit — 방문 정보
다음 정보를 제공한다.
- 주소
- 대중교통 및 자가용 안내
- 운영 시간
- 입장료
- 주차 정보
- 계절 행사 일정
- 공식 홈페이지 및 문의처

**운영 정책**
- 운영 시간, 요금, 행사 일정은 변경될 수 있으므로 공식 홈페이지의 최신 정보를 확인한 뒤 게시한다.
- 확인일 또는 “방문 전 공식 공지 확인” 문구를 표시한다.
- 현재 정보가 확인되지 않은 값은 임의로 채우지 않고 콘텐츠 데이터에서 미입력 상태로 관리한다.

### 5.9 Coupon Event — 방문 인증 이벤트

#### 5.9.1 이벤트 혜택
**아침고요수목원 카페 음료 50% 할인**

방문 인증을 완료한 참여자에게 이벤트 참여 쿠폰을 발급한다.

> 중요: 본 혜택은 수목원 및 카페 운영 주체의 공식 승인과 실제 사용 조건 확정 전까지 “제휴 승인 및 운영 조건 확인 필요” 상태다. 승인 전에는 실제 이용 가능한 혜택으로 오인하게 홍보하지 않는다.

#### 5.9.2 사용자 흐름
1. 사용자가 Coupon 섹션에서 이벤트 내용을 확인한다.
2. 이벤트 유의사항과 개인정보 처리 안내를 확인한다.
3. 사용자 식별 또는 로그인 절차를 진행한다.
4. 입장권 사진을 업로드한다.
5. 수목원 현장 배경이 확인되는 방문 사진을 업로드한다.
6. 필요한 경우 방문자 본인이 포함된 사진을 선택적으로 제출한다.
7. 필수 동의 및 제출을 완료한다.
8. 서버가 사용자별 기존 인증 여부와 이미지 중복 여부를 확인한다.
9. 검토 대기 또는 자동 검증 결과에 따라 인증 상태를 표시한다.
10. 승인되면 고유 쿠폰 코드를 발급한다.
11. 사용자는 쿠폰 상세 화면을 카페에서 제시한다.
12. 운영자는 쿠폰을 확인하고 사용 처리한다.

#### 5.9.3 인증 제한
- 한 사용자 계정당 승인된 방문 인증은 1회만 허용한다.
- 동시에 여러 요청을 보내더라도 중복 발급이 발생하지 않아야 한다.
- 이미 승인 또는 검토 중인 신청이 있으면 새 신청을 제한한다.
- 반려된 신청의 재제출 허용 여부와 횟수는 운영 정책으로 설정한다.
- 사용자 식별 수단(계정, 휴대전화 인증 등)은 실제 서비스 운영 정책에 따라 결정한다.

#### 5.9.4 사진 중복 및 재사용 방지
- 업로드 파일에 대해 SHA-256 등의 파일 해시를 계산해 완전히 동일한 파일의 재업로드를 탐지한다.
- perceptual hash(pHash 등)를 사용해 크기 변경, 압축, 일부 편집된 유사 이미지의 재사용을 탐지한다.
- 이미지 중복 판정은 자동 반려의 유일한 근거로 사용하지 않고, 임계값에 따라 관리자 검토 대상으로 보낼 수 있다.
- 입장권의 날짜·장소·유효성은 OCR 보조 검증 또는 관리자 검토로 확인한다.
- 사진 메타데이터(EXIF)는 조작될 수 있으므로 촬영 시각이나 GPS만으로 방문 사실을 확정하지 않는다.
- 얼굴 인식 및 생체정보 기반 식별은 사용하지 않는다.
- 동일 배경 사진이나 다른 방문자의 사진을 무단으로 재사용하는 시도를 검토할 수 있도록 관리자 검토 상태와 사유를 기록한다.

#### 5.9.5 쿠폰 정책
쿠폰 데이터에 포함할 항목:
- 고유 쿠폰 코드
- 사용자 ID
- 발급 일시
- 만료 일시
- 쿠폰 상태: issued / redeemed / expired / revoked
- 혜택: 카페 음료 50% 할인
- 사용 처리 일시
- 사용 처리 담당자 또는 검증 수단

다음 조건은 제휴처 확인 후 확정한다.
- 할인 대상 음료 및 제외 메뉴
- 다른 할인과 중복 적용 가능 여부
- 1인당 할인 적용 수량
- 쿠폰 유효 기간
- 평일·주말 및 공휴일 적용 여부
- 현장 사용 절차
- 할인 비용 정산 주체
- 쿠폰 취소 및 재발급 정책

#### 5.9.6 보안 및 부정 사용 방지
- 쿠폰 코드는 예측하기 어려운 충분한 길이의 난수로 생성한다.
- 쿠폰 검증 및 사용 처리는 서버에서 수행한다.
- 클라이언트에서 쿠폰 상태를 직접 변경할 수 없어야 한다.
- 쿠폰 사용 처리는 원자적으로 수행해 이중 사용을 막는다.
- 관리자 작업은 인증 및 권한 확인 후에만 허용한다.
- 민감한 사진은 공개 URL로 노출하지 않고 비공개 저장소에 보관한다.
- 업로드 파일 형식, 용량, MIME type을 서버에서 검증한다.
- 이미지 업로드에 악성 파일이 포함되지 않도록 검증 및 접근 통제를 적용한다.
- 반복 제출 및 자동화 공격에 대비해 요청 제한(rate limiting)을 적용한다.

#### 5.9.7 개인정보 보호
- 사진 제출 전에 수집 목적, 이용 항목, 보관 기간, 삭제 방법, 문의처를 안내한다.
- 방문 인증에 꼭 필요한 사진만 수집한다.
- 인물 사진은 필수 여부를 최소화하고, 꼭 필요하지 않다면 선택 제출로 설계한다.
- 이벤트 운영 및 쿠폰 검증에 필요한 기간이 지난 사진은 정책에 따라 삭제한다.
- 쿠폰 발급 및 사용 기록과 사진 원본의 보관 기간을 분리해 설정한다.
- 개인정보 처리방침 및 필요한 동의 문구는 실제 운영 주체의 법무·개인정보 담당 검토를 거친다.
- 개발·테스트 환경에 실제 사용자 사진을 사용하지 않는다.

#### 5.9.8 인증 상태 화면
- 신청 전: “방문 인증하고 이벤트에 참여하기”
- 검토 중: “인증 자료를 확인하고 있어요.”
- 승인: “방문 인증 완료! 쿠폰이 발급되었어요.”
- 반려: “인증이 완료되지 않았어요. 사유를 확인해 주세요.”
- 이미 참여: “방문 인증 이벤트는 1회 참여할 수 있어요.”
- 쿠폰 사용 완료: “사용 완료된 쿠폰입니다.”
- 만료: “쿠폰 사용 기간이 종료되었습니다.”

## 6. 기술 설계 제안

### 6.1 권장 아키텍처
본 프로젝트는 시각적 랜딩페이지와 사진 업로드·사용자별 1회 인증·쿠폰 발급을 포함한다. 따라서 정적 프론트엔드만으로 실제 이벤트 운영을 구현하지 않는다.

**권장 기본 구성(최종 확정 전 제안)**
- Frontend: Next.js + TypeScript
- Styling: Tailwind CSS
- Animation: CSS transition / Intersection Observer 기반 scroll reveal
- Backend / Database: Supabase 또는 동등한 서버 기반 서비스
- Authentication: 사용자별 중복 참여 방지를 위한 인증 수단
- Storage: 비공개 이미지 저장소
- Server Logic: 인증 검증, 이미지 해시 검사, 쿠폰 발급 및 사용 처리
- Deployment: 운영 주체가 승인한 배포 환경

기술 스택과 비용, 운영 주체의 계정 및 개인정보 처리 조건을 확인한 뒤 최종 선택한다.

### 6.3 API 초안
- `POST /api/visit-submissions` — 인증 자료 제출
- `GET /api/visit-submissions/me` — 내 인증 상태 조회
- `GET /api/coupons/me` — 내 쿠폰 조회
- `POST /api/coupons/validate` — 쿠폰 유효성 확인
- `POST /api/coupons/redeem` — 쿠폰 사용 처리
- `GET /api/admin/submissions` — 관리자 인증 신청 조회
- `POST /api/admin/submissions/{id}/approve` — 인증 승인
- `POST /api/admin/submissions/{id}/reject` — 인증 반려

모든 엔드포인트는 인증·권한·입력 검증을 수행한다. 관리자 API는 일반 사용자에게 노출하지 않는다.

### 6.4 관리자 기능
실제 쿠폰 이벤트 운영에는 최소한의 관리자 화면 또는 안전한 운영 도구가 필요하다.
- 인증 신청 목록 및 상세 사진 확인
- 중복 이미지 경고 확인
- 승인·반려 및 사유 입력
- 쿠폰 발급 상태 확인
- 쿠폰 코드 조회 및 사용 처리
- 이벤트 기간 및 쿠폰 유효 기간 설정
- 감사 로그 확인

관리자 화면의 구현 범위와 운영 주체는 착수 전에 확정한다.

## 14. Claude Code 개발 지침

Claude Code는 개발에 앞서 저장소의 기존 파일과 구조를 확인한다. 기존 프로젝트가 있다면 현재 기술 스택과 코딩 규칙을 우선 존중한다.

### 개발 순서
1. 프로젝트 구조와 기존 의존성 확인
2. 구현 계획 및 주요 파일 구조 제안
3. 디자인 토큰과 공통 컴포넌트 구성
4. 정적 랜딩페이지 구현
5. 반응형 및 접근성 구현
6. 콘텐츠 데이터를 분리해 관리
7. 서버·DB·스토리지 구성
8. 방문 인증 및 이미지 중복 검사 구현
9. 쿠폰 발급·검증·사용 처리 구현
10. 관리자 기능 구현
11. 테스트 및 보안 점검
12. 배포 전 운영 정책 확인

### 코드 작성 원칙
- TypeScript 타입을 명확히 정의한다.
- UI, 데이터, 서버 로직을 분리한다.
- 환경 변수와 비밀 키를 소스 코드에 하드코딩하지 않는다.
- 관리자 권한 및 쿠폰 상태 변경은 서버에서 검증한다.
- 이미지 업로드는 비공개 저장소를 기본으로 한다.
- 테스트 가능한 단위로 기능을 나눠 구현한다.
- 미확정 운영 정책은 임의로 결정하지 않고 설정값 또는 TODO로 분리한다.
- 실제 제휴 승인 전 할인 혜택을 확정된 서비스처럼 공개하지 않는다.

### 개발 완료 정의
- P0 기능이 테스트를 통과한다.
- 모든 핵심 화면이 모바일과 데스크톱에서 정상 작동한다.
- 인증 중복 및 쿠폰 이중 사용을 방지한다.
- 운영 정책 미확정 항목이 명시되어 있다.
- 개인정보 처리와 관리자 권한이 검토되어 있다.
- 실제 운영 정보와 이미지 사용 권한이 확인되어 있다.

## 15. 최종 제품 방향 요약

「숲길 따라」는 겨울철 아침고요수목원의 자연과 정원을 감성적인 에디토리얼 디자인으로 소개하는 여행 홍보 페이지다.

화이트와 아이보리를 바탕으로 포레스트 그린을 강조하고, 겨울 풍경의 대형 이미지, 인포그래픽, 절제된 스크롤 애니메이션을 활용한다. 주요 고객은 자연과 식물을 좋아하는 30대 성인 남녀이며, 겨울 체험, 방문 준비, 생태 정보, 방문 안내를 한 페이지에서 제공한다.

방문 인증 이벤트는 사용자별 1회 참여를 원칙으로 하며, 입장권 및 현장 사진의 중복·재사용을 탐지하고 승인 후 고유 쿠폰을 발급한다. 쿠폰 혜택은 아침고요수목원 카페 음료 50% 할인으로 기획하되, 실제 운영은 제휴 승인과 세부 이용 조건 확정 후 시작한다.
